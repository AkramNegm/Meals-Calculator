# Meals-Note
my web app that noted my new added meals  
Daily Logging:  Select the date and meal type (Breakfast, Lunch, Dinner, Snack).
Detailed Notes: Add custom names and descriptions for every food item.
Macro Tracking: Input the exact grams of protein, carbs, and fats for each meal.
Running History:Displays a neatly formatted, updated list of all meals logged.
